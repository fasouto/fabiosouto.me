Okay, this might be one of the less interesting projects on this page. I built it to fiddle with Claude Code right when it launched, and back then the context window was very limited, so a collection of small self-contained utilities seemed like a perfect fit: each calculator lives in its own file with minimal context to manage.

I created a design system and started prompting. The results were mixed, and I found myself switching back to manual coding more often than expected. Looking back, I was still learning how to work effectively with AI tools, and this was using an earlier model.

The site has plenty of random utilities. My favourite is the [LinkedIn post generator](https://infiniteutils.com/internet/linkedin-post-generator).

The project taught me a lot about where AI coding helps and where it doesn't. I haven't invested much time since: the calculator space is crowded and hard to differentiate.
